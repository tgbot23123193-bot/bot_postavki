## 📸 АНАЛИЗ СКРИНШОТА:

### Структура кнопки обновления на WB:

```html
<button class="...">
  <span class="Button-link__icon _ic2eqdYY+k Button-link__icon--left big _SMycGQd5t Button-link__icon--only-icon no_text__7w1r+5WD8R">
    <!-- Иконка обновления -->
  </span>
</button>
```

### Ключевые классы:
- `Button-link__icon` - главный класс иконки
- `Button-link__icon--only-icon` - иконка без текста
- Кнопка находится рядом с текстом: **"Данные обновлены 05.10.2025 в 12:01"**

## 🔧 СТРУКТУРА КОДА:

```python
# ШАГ 0: НАЖИМАЕМ КНОПКУ ОБНОВЛЕНИЯ
logger.info(f"🔄 Ищем кнопку обновления данных...")
refresh_button_selectors = [
    # 🎯 ТОЧНЫЕ селекторы с WB (из скриншота)
    'button:has(span.Button-link__icon)',  # ← ГЛАВНЫЙ СЕЛЕКТОР
    'span.Button-link__icon',
    '[class*="Button-link__icon"]',
    'button[class*="Button-link"]',
    'button:near(:text("Данные обновлены"))',
    # ... остальные резервные селекторы
]

refresh_clicked = False
for selector in refresh_button_selectors:
    try:
        element = await page.query_selector(selector)
        if element and await element.is_visible():
            await element.click()
            logger.info(f"✅ Нажал кнопку обновления: {selector}")
            refresh_clicked = True
            await asyncio.sleep(2)  # Ждем обновления данных
            break
    except Exception as e:
        logger.debug(f"⚠️ Не удалось кликнуть по {selector}: {e}")
        continue

if refresh_clicked:
    logger.info("✅ Данные обновлены!")
else:
    logger.warning("⚠️ Кнопка обновления не найдена, продолжаю без обновления")
```

### Playwright селекторы:

1. **`button:has(span.Button-link__icon)`**

4. **`span.Button-link__icon`**
   - Прямой селектор по классу (если иконка кликабельна напрямую)
