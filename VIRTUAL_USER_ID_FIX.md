# ✅ Исправлена параллельная работа - каждая задача изолирована!

## 🎯 Проблема

Все задачи работали в одной вкладке, хотя создавалось 3 вкладки.

### Причина:
Когда несколько задач работали одновременно, они **перезаписывали друг друга** в `browser_manager._browsers[user_id]`!

```python
# Задача #1 подменяет:
browser_manager._browsers[1373289742] = task_browser_1  # Вкладка #1

# Задача #2 ПЕРЕЗАПИСЫВАЕТ:
browser_manager._browsers[1373289742] = task_browser_2  # Вкладка #2 ← ОНА ПОБЕЖДАЕТ!

# Результат: обе задачи используют вкладку #2! ❌
```

## ✅ Решение

Теперь каждая задача получает **ВИРТУАЛЬНЫЙ user_id** и регистрируется отдельно!

---

## 🔧 Как работает

### Виртуальные user_id:

```python
# Реальный user_id = 1373289742

# Задача #1:
virtual_user_id = 1373289742 * 1000 + 1 = 1373289742001

# Задача #2:
virtual_user_id = 1373289742 * 1000 + 2 = 1373289742002

# Задача #3:
virtual_user_id = 1373289742 * 1000 + 3 = 1373289742003

# Теперь в browser_manager._browsers:
{
  1373289742001: браузер с вкладкой #1,  ← Задача #1
  1373289742002: браузер с вкладкой #2,  ← Задача #2
  1373289742003: браузер с вкладкой #3   ← Задача #3
}

✅ Каждая задача изолирована!
```

## 🔧 Что изменилось

**Файл:** `wb_bot/app/bot/handlers/redistribution.py`

### Было (КОНФЛИКТ):
```python
# Подменяем браузер для ОДНОГО user_id
browser_manager._browsers[user_id] = task_browser

# ❌ Следующая задача ПЕРЕЗАПИШЕТ это!
```

### Стало (ИЗОЛЯЦИЯ):
```python
# Создаем ВИРТУАЛЬНЫЙ user_id для этой задачи
virtual_user_id = user_id * 1000 + int(task.task_id)

# Регистрируем виртуальный браузер для этой задачи
browser_manager._browsers[virtual_user_id] = task_browser

logger.info(f"📄 Задача #{task.task_id}: виртуальный ID: {virtual_user_id}")

# ✅ Каждая задача в своем слоте!

# Выполняем с виртуальным ID
await redistribution_service.close_and_reopen_redistribution(virtual_user_id, task.article)
await redistribution_service.select_warehouse(virtual_user_id, task.source_warehouse)
await redistribution_service.select_destination_warehouse(virtual_user_id, task.destination_warehouse)
await redistribution_service.input_quantity(virtual_user_id, task.quantity)

# После завершения - удаляем виртуальный браузер
del browser_manager._browsers[virtual_user_id]
```

## 🧹 Очистка

Виртуальные браузеры автоматически удаляются:

1. **При успешном завершении:**
```python
del browser_manager._browsers[virtual_user_id]
```

2. **При достижении лимита попыток:**
```python
if virtual_user_id in browser_manager._browsers:
    del browser_manager._browsers[virtual_user_id]
```

3. **При отмене задачи:**
```python
if virtual_user_id in browser_manager._browsers:
    del browser_manager._browsers[virtual_user_id]
```

4. **При критической ошибке:**
```python
if virtual_user_id in browser_manager._browsers:
    del browser_manager._browsers[virtual_user_id]
```
