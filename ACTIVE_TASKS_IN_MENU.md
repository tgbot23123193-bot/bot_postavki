# ✅ Показ активных задач при входе в меню перераспределения

## 🎯 Что сделано

Теперь при входе в меню перераспределения автоматически показываются активные задачи, если они есть!

---

## 🔧 Как работает

### Сценарий 1: Есть активные задачи

```
1. Пользователь запускает 2 задачи перераспределения
   → Задачи работают в фоне

2. Пользователь выходит в главное меню
   → Задачи продолжают работать

3. Пользователь возвращается в "Перераспределение"
   → ✅ АВТОМАТИЧЕСКИ показываются активные задачи!

Отображается:
📋 Активные задачи (2/3)

🔄 Задача #1
📦 Артикул: 446796490
🏪 Рязань (Пошевское) → Коледино
🔢 Количество: 50 шт
📊 Попыток: 1
📍 Статус: ❌ Попытка #1: Ошибка

🔄 Задача #2
📦 Артикул: 446796490
🏪 Рязань (Пошевское) → Казань
🔢 Количество: 50 шт
📊 Попыток: 0
📍 Статус: 🚀 Запускаю...

Кнопки:
[🛑 Остановить #1]
[🛑 Остановить #2]
[➕ Добавить задачу]
[🏠 Главное меню]
```

### Сценарий 2: Нет активных задач

```
1. Пользователь заходит в "Перераспределение"
   → Нет активных задач

2. Показывается обычное меню:

🔄 Перераспределение остатков

Автоматизация работы со страницей:
📋 Отчет по остаткам на складе

✅ Браузерная сессия активна
✅ Авторизация в WB подтверждена
📅 Последняя авторизация: 03.10.2025 12:00

Выберите действие:

Кнопки:
[🚀 Начать перераспределение]
[📋 Активные задачи (до 3)]
[📋 Инструкция]
[🏠 Главное меню]
```

## 🔧 Что изменилось

**Файл:** `wb_bot/app/bot/handlers/redistribution.py`

**Функция:** `show_redistribution_menu`

### Было:
```python
@router.callback_query(F.data == "redistribution_menu")
async def show_redistribution_menu(callback: CallbackQuery):
    # ... проверки браузера ...
    
    # Показываем обычное меню
    menu_text = (
        "🔄 Перераспределение остатков\n\n"
        "Выберите действие:"
    )
    
    await callback.message.edit_text(
        menu_text,
        reply_markup=get_redistribution_menu()
    )
```

### Стало:
```python
@router.callback_query(F.data == "redistribution_menu")
async def show_redistribution_menu(callback: CallbackQuery):
    # ... проверки браузера ...
    
    # ✅ ПРОВЕРЯЕМ АКТИВНЫЕ ЗАДАЧИ
    user_tasks = active_redistribution_tasks.get(user_id, {})
    
    if user_tasks:
        # ✅ Есть активные задачи - показываем их статус
        status_text = await show_active_tasks_status(user_id, callback.bot)
        keyboard = get_tasks_management_keyboard(user_id)
        
        await callback.message.edit_text(
            status_text,
            parse_mode="HTML",
            reply_markup=keyboard
        )
    else:
        # Нет активных задач - показываем обычное меню
        menu_text = (
            "🔄 Перераспределение остатков\n\n"
            "Выберите действие:"
        )
        
        await callback.message.edit_text(
            menu_text,
            reply_markup=get_redistribution_menu()
        )
```

## 📊 Преимущества

### 1. **Удобство:**
Не нужно искать кнопку "Активные задачи" - они показываются автоматически.

### 2. **Информативность:**
Сразу видно сколько задач работает и их статус.

### 3. **Быстрый доступ:**
Можно сразу остановить задачу или добавить новую.

### 4. **Контекстность:**
Меню меняется в зависимости от ситуации.

---

## 🎬 Примеры использования

### Пример 1: Проверка статуса задач

```
1. Запустили 3 задачи
2. Вышли в главное меню
3. Вернулись в "Перераспределение"
   → ✅ Сразу видим все 3 задачи и их статусы!
```

### Пример 2: Остановка задачи

```
1. Зашли в "Перераспределение"
   → Видим активные задачи
2. Нажали "Остановить #2"
   → Задача #2 остановлена
3. Видим обновленный список (осталось 2 задачи)
```

### Пример 3: Добавление новой задачи

```
1. Зашли в "Перераспределение"
   → Видим 2 активные задачи
2. Нажали "Добавить задачу"
   → Запускается процесс создания 3-й задачи
```
