## 📱 Тестирование в Telegram

### Тест 1: Один пользователь

1. Откройте бота в Telegram
2. Отправьте команду `/start`
3. Выберите функцию (например, "Перераспределение")
4. Начните процесс
5. Убедитесь что все работает

### Тест 2: Несколько пользователей одновременно

1. **Пользователь 1**: Откройте бота в своем аккаунте
2. **Пользователь 2**: Откройте бота в другом аккаунте (или попросите друга)
3. **Оба**: Начните работу с ботом одновременно
4. Проверьте что:
   - ✅ Оба пользователя могут работать независимо
   - ✅ Действия одного пользователя не влияют на другого
   - ✅ Каждый видит только свои данные
   - ✅ Браузеры не конфликтуют

### Тест 3: Остановка процесса

1. Начните любой процесс (охота, перераспределение)
2. Нажмите кнопку "🛑 Остановить"
3. Убедитесь что:
   - ✅ Процесс останавливается
   - ✅ Браузер закрывается
   - ✅ Можно начать новый процесс

## 🐛 Возможные проблемы и решения

### Проблема: "Браузер не запускается"

**Решение:**
```bash
# Переустановите Playwright браузеры
playwright install --force firefox
```

### Проблема: "Port already in use"

**Решение:**
- Это нормально! Система автоматически выбирает уникальные порты для каждого пользователя
- Если все же возникает конфликт, перезапустите бота

### Проблема: "Cookies не сохраняются"

**Решение:**
- Убедитесь что у бота есть права на запись в папку проекта
- Проверьте что папки `wb_user_data_*` создаются автоматически

### Проблема: "Несколько пользователей видят друг друга"

**Решение:**
- Это должно быть исправлено! Если проблема осталась:
  1. Остановите бота
  2. Удалите все папки `wb_user_data_*` и файлы `wb_cookies_*.json`
  3. Запустите бота снова
  4. Если проблема повторяется - напишите в поддержку
