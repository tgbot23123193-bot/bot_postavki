## 🎯 ПРОБЛЕМА:

Пользователь указал, что перед нажатием на кнопку **"Перераспределить остатки"** нужно сначала нажимать на **кнопку обновления** (refresh), которая находится рядом с текстом "Данные обновлены 05.10.2025 в 11:14".

## ✅ ЧТО СДЕЛАНО:

### 1. Метод `click_redistribution_menu`

**Файл:** `wb_bot/app/services/redistribution_service.py`

**Изменения:**
- Добавлен **ШАГ 0** - поиск и нажатие кнопки обновления данных
- Кнопка обновления нажимается **ПЕРЕД** кликом на "Перераспределить остатки"
- После нажатия обновления - ждем **2 секунды** для загрузки свежих данных

**Логика:**
```python
# ШАГ 0: НАЖИМАЕМ КНОПКУ ОБНОВЛЕНИЯ (рядом с "Данные обновлены...")
logger.info(f"🔄 Ищем кнопку обновления данных...")
refresh_button_selectors = [
    'button[aria-label*="бновить"]',
    'button[aria-label*="Обновить"]',
    'button[title*="бновить"]',
    'button[title*="Обновить"]',
    'button:has(svg[data-testid*="refresh"])',
    'button:has(svg[data-testid*="reload"])',
    '[data-testid*="refresh-button"]',
    '[data-testid*="reload-button"]',
    'button.refresh-button',
    'button.reload-button'
]

refresh_clicked = False
for selector in refresh_button_selectors:
    try:
        element = await page.query_selector(selector)
        if element and await element.is_visible():
            await element.click()
            logger.info(f"✅ Нажал кнопку обновления: {selector}")
            refresh_clicked = True
            # Ждем обновления данных
            await asyncio.sleep(2)
            break
    except Exception as e:
        logger.debug(f"⚠️ Не удалось кликнуть по {selector}: {e}")
        continue

if refresh_clicked:
    logger.info("✅ Данные обновлены!")
else:
    logger.warning("⚠️ Кнопка обновления не найдена, продолжаю без обновления")

# ШАГ 1: Теперь кликаем по "Перераспределить остатки"
```

## 🔍 СЕЛЕКТОРЫ ДЛЯ ПОИСКА КНОПКИ ОБНОВЛЕНИЯ:

Бот ищет кнопку обновления по следующим селекторам (в порядке приоритета):

1. `button[aria-label*="бновить"]` - Кнопка с aria-label содержащим "бновить" или "обновить"
2. `button[aria-label*="Обновить"]` - Кнопка с aria-label "Обновить"
3. `button[title*="бновить"]` - Кнопка с title содержащим "бновить"
4. `button[title*="Обновить"]` - Кнопка с title "Обновить"
5. `button:has(svg[data-testid*="refresh"])` - Кнопка с SVG иконкой refresh
6. `button:has(svg[data-testid*="reload"])` - Кнопка с SVG иконкой reload
7. `[data-testid*="refresh-button"]` - Элемент с data-testid содержащим "refresh-button"
8. `[data-testid*="reload-button"]` - Элемент с data-testid содержащим "reload-button"
9. `button.refresh-button` - Кнопка с классом "refresh-button"
10. `button.reload-button` - Кнопка с классом "reload-button"

- **Поиск кнопки обновления:** ~0.1-0.5 сек (перебор селекторов)

- **Ожидание обновления данных:** **2 секунды** ⏳
- **Клик на "Перераспределить остатки":** ~0.1-0.3 сек
