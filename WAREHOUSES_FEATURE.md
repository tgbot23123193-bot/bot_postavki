# ✅ Добавлен функционал "Доступные склады" в автомониторинг

## 🎯 Что было добавлено

В раздел "Автомониторинг" добавлена кнопка **"🏬 Доступные склады"** с полноценным функционалом просмотра складов через API WB с пагинацией.

## 📝 Изменения

**Файл:** `wb_bot/app/bot/handlers/browser_booking.py`

### 1. Новая кнопка в меню автомониторинга

```python
keyboard = InlineKeyboardMarkup(inline_keyboard=[
    [InlineKeyboardButton(text="🏬 Доступные склады", callback_data="browser_show_warehouses")],  # ← НОВАЯ
    [InlineKeyboardButton(text="📅 Выбрать период", callback_data="browser_select_period")],
    [InlineKeyboardButton(text="📊 Макс. коэффициент", callback_data="browser_select_coef")],
    [InlineKeyboardButton(text="✅ Начать мониторинг", callback_data="browser_start_monitor")],
    [InlineKeyboardButton(text="⬅️ Назад", callback_data="browser_menu")]
])
```

### 2. Константы для пагинации

```python
WAREHOUSES_PER_PAGE = 5  # Количество складов на одной странице
browser_warehouses_data = {}  # Хранилище данных для пагинации
```

### 3. Обработчик получения складов

```python
@router.callback_query(F.data == "browser_show_warehouses")
async def browser_show_warehouses(callback: CallbackQuery):
    """Показать доступные склады через API."""
```

**Логика работы:**
1. ✅ Проверяет наличие API ключа у пользователя
2. ✅ Показывает сообщение о загрузке
3. ✅ Получает список всех складов через `api_client.get_warehouses()`
4. ✅ Берет топ-30 складов для анализа
5. ✅ Получает коэффициенты приёмки через `api_client.get_acceptance_coefficients()`
6. ✅ Группирует слоты по складам
7. ✅ Сохраняет данные для пагинации
8. ✅ Отображает первую страницу

### 4. Функция отображения страницы складов

```python
async def show_browser_warehouses_page(message, user_id: int, page: int):
    """Отображает страницу складов с пагинацией для автомониторинга."""
```

**Функционал:**
- ✅ Фильтрует склады со слотами и без
- ✅ Рассчитывает пагинацию (страницы)
- ✅ Показывает информацию о каждом складе:
  - 🏬 Название склада
  - 🆔 ID склада
  - 🎯 Количество доступных слотов
  - 📅 Ближайшие даты (до 3 дат)
- ✅ Отображает навигацию (⬅️ Пред. / След. ➡️)
- ✅ Кнопка "🔄 Обновить" для повторного запроса
- ✅ Кнопка "⬅️ Назад" для возврата

### 5. Обработчик пагинации

```python
@router.callback_query(F.data.startswith("browser_wh_page:"))
async def browser_warehouses_page_handler(callback: CallbackQuery):
    """Обработчик пагинации складов в автомониторинге."""
```

**Логика:**
- Извлекает номер страницы из callback data
- Получает сохраненные данные пользователя
- Отображает запрошенную страницу

## 📝 Примечания

- **Производительность:** Анализируется топ-30 складов для быстрой работы
- **Пагинация:** 5 складов на страницу для удобства чтения
- **Кэширование:** Данные сохраняются в памяти для быстрой навигации между страницами
- **Источник данных:** WB Supplies API через `WBSuppliesAPIClient`
- **Логика копирована из:** `wb_bot/app/bot/handlers/monitoring_simple.py`
