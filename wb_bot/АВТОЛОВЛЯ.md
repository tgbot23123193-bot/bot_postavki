## 📚 Использование

### В боте:

Пользователь выбирает поставку и склад, затем нажимает кнопку "🤖 Автобронирование".
Бот автоматически:
1. Запускает мониторинг слотов каждые 10 секунд
2. Фильтрует слоты по коэффициентам
3. Автоматически бронирует первый подходящий слот
4. Отправляет уведомление о результате

### Программно:

```python
from app.services.auto_booking_service import auto_booking_service

# Callback для успешного бронирования
async def on_success(result):
    print(f"🎉 Забронировано! Дата: {result['date']}")

# Callback для ошибок
async def on_error(error_msg):
    print(f"❌ Ошибка: {error_msg}")

# Запуск автобронирования
await auto_booking_service.start_auto_booking(
    user_id=123456789,
    supply_id="WB-001",
    supply_name="Поставка №1",
    warehouse_id=1234,
    warehouse_name="Склад Подольск",
    date_from="2024-01-01",
    date_to="2024-12-31",
    max_coefficient=1,      # Только слоты с коэфф. 0 или 1
    check_interval=10,      # Проверка каждые 10 секунд
    mode="api",             # Режим: "api" или "browser"
    on_success=on_success,
    on_error=on_error
)

# Проверка статуса
if auto_booking_service.is_active(user_id):
    session = auto_booking_service.get_session(user_id)
    print(f"Проверок выполнено: {session.checks_count}")

# Остановка
await auto_booking_service.stop_auto_booking(user_id)
```

## 🎯 Режимы работы

### 1. API режим (по умолчанию)
- **Скорость:** Очень быстро (10 секунд между проверками)
- **Надежность:** Высокая
- **Требования:** Только API ключ WB
- **Рекомендуется:** Для большинства случаев

### 2. Browser режим
- **Скорость:** Медленнее (имитация действий пользователя)
- **Надежность:** Средняя (зависит от стабильности сайта WB)
- **Требования:** Браузер + авторизация в WB
- **Рекомендуется:** Когда API не работает или заблокирован

## ⚙️ Настройки

### Параметры по умолчанию:
- **check_interval:** 10 секунд (можно изменить от 5 до 60)
- **max_coefficient:** None (все коэффициенты, можно ограничить)
- **mode:** "api" (можно изменить на "browser")

### Рекомендуемые настройки:
- Для быстрой ловли: `check_interval=5, mode="api"`
- Для экономии API запросов: `check_interval=30, mode="api"`
- При проблемах с API: `check_interval=10, mode="browser"`

## 🐛 Известные проблемы и решения

### Проблема: "Автобронирование не активно"
**Решение:** Проверьте что API ключ добавлен и активен

### Проблема: "Слоты не найдены"
**Решение:** 
- Проверьте период дат (date_from и date_to)
- Убедитесь что на складе есть доступные слоты
- Попробуйте изменить max_coefficient

### Проблема: "Не удалось забронировать"
**Решение:**
- Слот мог быть занят другим пользователем
- Автобронирование продолжит поиск других слотов
