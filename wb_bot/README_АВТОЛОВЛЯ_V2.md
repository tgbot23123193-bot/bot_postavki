## 🚀 КАК РАБОТАЕТ

### Режим 1: API (по умолчанию)
```
Пользователь → Выбирает поставку и склад → Нажимает "🤖 Автобронирование"
     ↓
Бот проверяет API WB каждые 10 секунд
     ↓
Находит подходящий слот → Автоматически бронирует → Уведомляет пользователя
```

### Режим 2: Browser (как Chrome расширение)
```
Пользователь → Выбирает поставку и склад → Нажимает "🤖 Автобронирование" (browser mode)
     ↓
Бот открывает браузер WB → Кликает "Запланировать поставку"
     ↓
Открывается popup с календарем
     ↓
Есть подходящие даты?
     ├─ ДА → Выбирает дату → Подтверждает → Уведомляет пользователя → Продолжает искать новые
     └─ НЕТ → Закрывает popup через ESC → Ждет интервал → Повторяет попытку
```

## 📋 СПИСОК КОМАНД ДЛЯ УСТАНОВКИ

### 1. Установка Python зависимостей
```bash
cd wb_bot

# Основные зависимости
pip install -r ../requirements.txt

# Playwright для автоматизации браузера
pip install playwright==1.40.0

# Установка браузеров
playwright install firefox
# или все браузеры
playwright install
```

### 2. Установка PostgreSQL

**Windows:**
```bash
# Скачать: https://www.postgresql.org/download/windows/
# Или через winget:
winget install PostgreSQL.PostgreSQL
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

**macOS:**
```bash
brew install postgresql
brew services start postgresql
```

### 3. Создание базы данных
```bash
psql -U postgres

CREATE DATABASE wb_bot_db;
CREATE USER wb_bot_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE wb_bot_db TO wb_bot_user;
\q
```

### 4. Настройка .env файла
```bash
cd wb_bot
cp env.example .env

# Отредактировать .env:
# BOT_TOKEN=your_bot_token
# DATABASE_URL=postgresql://wb_bot_user:password@localhost:5432/wb_bot_db
# ENCRYPTION_KEY=your_32_char_key
```

### 5. Применение миграций
```bash
cd wb_bot
alembic upgrade head
```

### 6. Запуск бота
```bash
cd wb_bot
python app/main.py
```

## 🐛 УСТРАНЕНИЕ ПРОБЛЕМ

### "Автобронирование сразу останавливается"
**Решение:** Проверьте API ключ WB в боте

### "Модальное окно не закрывается через ESC"
**Решение:** Обновлена логика - теперь пробует 3 раза + кнопку + overlay

### "Нет подходящих дат постоянно"
**Решение:** 
- Проверьте фильтры (dateFrom, dateTo, maxCoefficient)
- Убедитесь что на складе есть доступные слоты
- Увеличьте maxCoefficient

### "Browser mode не работает"
**Решение:**
```bash
# Переустановить браузеры
playwright install firefox --with-deps
```
