## 2️⃣ Настройка базы данных PostgreSQL

### Установка PostgreSQL:

**Windows:**
```bash
# Скачать с официального сайта:
# https://www.postgresql.org/download/windows/

# Или через Chocolatey:
choco install postgresql

# Или через winget:
winget install PostgreSQL.PostgreSQL
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

**macOS:**
```bash
brew install postgresql
brew services start postgresql
```

### Создание базы данных:
```bash
# Войти в PostgreSQL
psql -U postgres

# Создать базу данных
CREATE DATABASE wb_bot_db;

# Создать пользователя
CREATE USER wb_bot_user WITH PASSWORD 'your_password_here';

# Дать права пользователю
GRANT ALL PRIVILEGES ON DATABASE wb_bot_db TO wb_bot_user;

# Выйти
\q
```

## 3️⃣ Настройка переменных окружения

### Создать файл `.env`:
```bash
# В директории wb_bot создать файл .env
cd wb_bot
copy env.example .env  # Windows
# или
cp env.example .env    # Linux/macOS
```

### Заполнить `.env`:
```env
# Telegram Bot
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789,987654321

# PostgreSQL Database
DATABASE_URL=postgresql://wb_bot_user:your_password_here@localhost:5432/wb_bot_db

# Encryption key для хранения API ключей
ENCRYPTION_KEY=your_32_character_encryption_key_here

# WB API (опционально, для тестов)
WB_API_KEY=your_wildberries_api_key

# Redis (опционально)
REDIS_URL=redis://localhost:6379

# Режим работы
ENVIRONMENT=development
DEBUG=True
```

## 🔟 Производственное развертывание

### Создание systemd сервиса (Linux):
```bash
# Создать файл сервиса
sudo nano /etc/systemd/system/wb_bot.service
```

```ini
[Unit]
Description=WB Supplies Bot
After=network.target postgresql.service

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/bot_postavki/wb_bot
Environment="PATH=/path/to/venv/bin"
ExecStart=/path/to/venv/bin/python app/main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# Применить и запустить
sudo systemctl daemon-reload
sudo systemctl enable wb_bot
sudo systemctl start wb_bot

# Проверить статус
sudo systemctl status wb_bot

# Посмотреть логи
sudo journalctl -u wb_bot -f
```
