## ⚙️ УСТАНОВКА (если еще не установили)

### Windows:
```bash
cd wb_bot
pip install -r ../requirements.txt
pip install playwright
playwright install firefox
```

### Linux:
```bash
cd wb_bot
pip install -r ../requirements.txt
pip install playwright
playwright install firefox --with-deps
```

### PostgreSQL:
```bash
# Windows
winget install PostgreSQL.PostgreSQL

# Linux
sudo apt install postgresql

# Создать БД
psql -U postgres
CREATE DATABASE wb_bot_db;
CREATE USER wb_bot_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE wb_bot_db TO wb_bot_user;
\q

# Миграции
cd wb_bot
alembic upgrade head
```

### Запуск:
```bash
cd wb_bot
python app/main.py
```

## 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема: Бот не запускается
```bash
# Проверить зависимости
pip list | grep aiogram
pip list | grep playwright

# Переустановить если нужно
pip install aiogram playwright psycopg2-binary
```

### Проблема: База данных не работает
```bash
# Проверить PostgreSQL
psql -U postgres -c "SELECT version();"

# Применить миграции
cd wb_bot
alembic upgrade head
```

### Проблема: Playwright не работает
```bash
# Переустановить браузеры
playwright install firefox --with-deps
```
