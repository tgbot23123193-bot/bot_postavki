# ✅ Исправлена кнопка "Добавить задачу"

## 🎯 Проблема

При нажатии на кнопку "➕ Добавить задачу" в списке активных задач появлялась ошибка "Произошла ошибка".

### Причина:
Кнопка "Добавить задачу" имела `callback_data="redistribution_menu"`, что вызывало функцию `show_redistribution_menu`, которая снова проверяла активные задачи и показывала их же! Получался бесконечный цикл.

```python
# БЫЛО (НЕПРАВИЛЬНО):
InlineKeyboardButton(
    text="➕ Добавить задачу",
    callback_data="redistribution_menu"  # ❌ Показывает активные задачи снова!
)
```

---

## ✅ Решение

Теперь кнопка "Добавить задачу" вызывает тот же обработчик, что и "Начать перераспределение" - запрос артикула для создания новой задачи!

```python
# СТАЛО (ПРАВИЛЬНО):
InlineKeyboardButton(
    text="➕ Добавить задачу",
    callback_data=RedistributionCallback(action="start").pack()  # ✅ Запускает создание задачи!
)
```

## 🔧 Что изменилось

**Файл:** `wb_bot/app/bot/handlers/redistribution.py`

**Функция:** `get_tasks_management_keyboard`

# Кнопка добавления новой задачи (если меньше 3)
if len(user_tasks) < 3:

### Стало:

# Кнопка добавления новой задачи (если меньше 3)
if len(user_tasks) < 3:

        InlineKeyboardButton(
            text="➕ Добавить задачу",

## 🎬 Как работает теперь

### Сценарий:

```
1. Пользователь заходит в "Перераспределение"
   → Видит активные задачи (2/3)

2. Нажимает "➕ Добавить задачу"
   → ✅ Бот запрашивает артикул для новой задачи!

3. Вводит артикул
   → Бот запрашивает API ключ и показывает склады

4. Выбирает склады и количество
   → ✅ Создается 3-я задача!

5. Возвращается в меню "Перераспределение"
   → Видит уже 3 активные задачи
```
