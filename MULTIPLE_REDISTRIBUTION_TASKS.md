# ✅ Множественное перераспределение (до 3-х поставок одновременно)

## 🎯 Что было реализовано

Система одновременного перераспределения до 3-х поставок, где каждая работает параллельно с той же логикой что и раньше.

## 📊 Основные возможности

### 1. **Параллельное выполнение задач**
- ✅ Можно создать до 3-х задач перераспределения одновременно
- ✅ Каждая задача работает независимо в своей вкладке браузера
- ✅ Используется та же логика что и раньше (активные периоды, попытки, и т.д.)

### 2. **Создание задач по отдельности**
- ✅ Каждая задача создается через стандартный процесс (артикул → склад откуда → склад куда → количество)
- ✅ После ввода количества показывается сообщение "🚀 Запускаю перераспределение"
- ✅ Задача начинает работать в фоне

### 3. **Отображение статусов**
- ✅ Показывается список всех активных задач с их статусами:
  - 📦 Артикул
  - 🏪 Склады (откуда → куда)
  - 🔢 Количество
  - 📊 Попыток сделано
  - 📌 Текущий статус (ловлю, жду период, поймана, и т.д.)

### 4. **Управление задачами**
- ✅ Кнопка "🛑 Остановить #N" для каждой задачи
- ✅ Кнопка "➕ Добавить задачу" (если меньше 3)
- ✅ Кнопка "🏠 Главное меню" всегда внизу

### 5. **Уведомления**
- ✅ При успешном захвате: "🎉 ПОСТАВКА ПОЙМАНА!" с деталями задачи
- ✅ При достижении лимита попыток: уведомление о завершении
- ✅ При ошибке: уведомление с описанием проблемы

### 1. Хранилище активных задач

```python
# Глобальное хранилище (в памяти)
active_redistribution_tasks = {}  # {user_id: {task_id: RedistributionTask}}

class RedistributionTask:
    """Класс для хранения информации об активной задаче."""
    def __init__(self, task_id, article, source_warehouse, destination_warehouse, quantity):
        self.task_id = task_id
        self.article = article
        self.source_warehouse = source_warehouse
        self.destination_warehouse = destination_warehouse
        self.quantity = quantity
        self.status = "⏳ Ждем запуска..."
        self.attempts = 0
        self.started_at = None
        self.message_id = None
        self.asyncio_task = None  # asyncio.Task для отмены
```

async def run_redistribution_task_in_background(user_id, task, bot):

### 3. UI для управления задачами

```python
async def show_active_tasks_status(user_id, bot) -> str:
    """Формирует текст со статусами всех задач."""
    text = f"📋 <b>Активные задачи</b> ({len(user_tasks)}/3)\n\n"
    
    for task in user_tasks.values():
        text += (
            f"🔄 <b>Задача #{task.task_id}</b>\n"
            f"📦 Артикул: {task.article}\n"
            f"🏪 {source} → {destination}\n"
            f"📊 Попыток: {task.attempts}\n"
            f"📌 Статус: {task.status}\n\n"
        )
    
    return text

def get_tasks_management_keyboard(user_id):
    """Создает клавиатуру с кнопками управления."""
    keyboard = []
    
    # Кнопки остановки каждой задачи
    for task in user_tasks.values():
        keyboard.append([
            InlineKeyboardButton(f"🛑 Остановить #{task.task_id}", ...)
        ])
    
    # Кнопка добавления (если < 3)
    if len(user_tasks) < 3:
        keyboard.append([
            InlineKeyboardButton("➕ Добавить задачу", ...)
        ])
    
    # Главное меню
    keyboard.append([
        InlineKeyboardButton("🏠 Главное меню", ...)
    ])
    
    return InlineKeyboardMarkup(inline_keyboard=keyboard)
```

### 4. Создание новой задачи

```python
@router.message(RedistributionStates.waiting_for_quantity)
async def process_quantity_input(message: Message, state: FSMContext):
    """После ввода количества создает задачу."""
    
    # Проверка лимита
    if len(user_tasks) >= 3:
        await message.answer("⚠️ Достигнут лимит (3 задачи)")
        return
    
    # Создание задачи
    task_id = str(len(user_tasks) + 1)
    task = RedistributionTask(task_id, article, source, destination, quantity)
    user_tasks[task_id] = task
    
    # Сообщение "Запускаю перераспределение"
    await message.answer(
        f"🚀 <b>Запускаю перераспределение</b>\n\n"
        f"✅ <b>Задача #{task_id} создана</b>\n"
        f"📦 Артикул: {article}\n"
        f"🏪 {source} → {destination}\n"
        f"🔢 Количество: {quantity} шт\n\n"
        f"⏳ Инициализация..."
    )
    
    # Запуск в фоне
    task.asyncio_task = asyncio.create_task(
        run_redistribution_task_in_background(user_id, task, bot)
    )
    
    # Показ статусов всех задач
    status_text = await show_active_tasks_status(user_id, bot)
    keyboard = get_tasks_management_keyboard(user_id)
    
    await message.answer(status_text, reply_markup=keyboard)
```

## 🔄 Статусы задач

### Типы статусов:

| Статус | Описание |
|--------|----------|
| `⏳ Ждем запуска...` | Задача создана, но еще не начала работать |
| `🚀 Запускаю...` | Инициализация задачи |
| `🔥 Попытка #N (активный режим)` | Попытка в активный период (частые попытки) |
| `⏳ Попытка #N (до активного: M мин)` | Попытка вне активного периода |
| `📦 Попытка #N: Склад недоступен` | Склад временно недоступен в WB |
| `⏰ Попытка #N: Лимит исчерпан` | Достигнут дневной лимит WB |
| `❌ Попытка #N: Ошибка` | Техническая ошибка |
| `🎉 ПОЙМАНА!` | Поставка успешно забронирована |
| `⚠️ Лимит попыток (N)` | Достигнут лимит попыток |
| `🛑 Отменена` | Задача остановлена пользователем |
| `❌ Критическая ошибка` | Критическая ошибка в задаче |
