## 📸 АНАЛИЗ СКРИНШОТОВ:

На скриншотах видно:
1. **Синяя круглая иконка обновления** - это `span.Button-link__icon`
2. **Текст рядом:** "Данные обновлены 05.10.2025 в 12:39"

### Структура:
```html
<div>
  <span class="Text...">Данные обновлены 05.10.2025 в 12:39</span>
  <span class="Button-link__icon ..."><!-- Иконка обновления --></span>
</div>
```

---

## ✅ НОВАЯ ЛОГИКА ПОИСКА:

### Алгоритм:

```python
1. Находим текст "Данные обновлены" на странице
   ↓
2. Находим ВСЕ элементы span.Button-link__icon на странице
   ↓
3. Берем ПЕРВЫЙ ВИДИМЫЙ элемент
   ↓
4. Кликаем по этой иконке
   ↓
5. Ждем 2 секунды (данные обновляются)
```

### Код:

```python
# ШАГ 0: НАЖИМАЕМ КНОПКУ ОБНОВЛЕНИЯ (синяя круглая иконка)
logger.info(f"🔄 Ищем кнопку обновления данных...")

refresh_clicked = False
try:
    # 1. Ищем текст "Данные обновлены"
    text_element = await page.query_selector('text=/Данные обновлены/')
    if text_element:
        logger.info("✅ Нашел текст 'Данные обновлены'")
        
        # 2. Ищем все span.Button-link__icon на странице
        nearby_buttons = await page.query_selector_all('span.Button-link__icon')
        logger.info(f"🔍 Найдено {len(nearby_buttons)} элементов с классом Button-link__icon")
        
        # 3. Берем ПЕРВЫЙ ВИДИМЫЙ элемент
        for btn in nearby_buttons:
            try:
                is_visible = await btn.is_visible()
                if is_visible:
                    # Логируем позицию для отладки
                    box = await btn.bounding_box()
                    logger.info(f"🎯 Найдена видимая иконка на позиции: {box}")
                    
                    # 4. Кликаем!
                    await btn.click()
                    logger.info(f"✅ Нажал кнопку обновления (иконка Button-link__icon)")
                    refresh_clicked = True
                    
                    # 5. Ждем обновления данных
                    await asyncio.sleep(2)
                    break
            except Exception as e:
                logger.debug(f"⚠️ Пропускаю элемент: {e}")
                continue
    else:
        logger.warning("⚠️ Текст 'Данные обновлены' не найден")
except Exception as e:
    logger.warning(f"⚠️ Ошибка при поиске кнопки обновления: {e}")

if refresh_clicked:
    logger.info("✅ Данные обновлены!")
else:
    logger.warning("⚠️ Кнопка обновления не найдена, продолжаю без обновления")
```

## ⚙️ ТЕХНИЧЕСКИЕ ДЕТАЛИ:

### `query_selector('text=/Данные обновлены/')`
- Playwright синтаксис для поиска текста по регулярному выражению
- `/Данные обновлены/` - найдет любой текст, содержащий эту фразу

### `query_selector_all('span.Button-link__icon')`
- CSS селектор для поиска ВСЕХ элементов
- Возвращает список (не один элемент!)

### `bounding_box()`
- Возвращает координаты элемента: `{x: 450, y: 120, width: 24, height: 24}`
- Полезно для отладки - можно понять ГДЕ на странице элемент
