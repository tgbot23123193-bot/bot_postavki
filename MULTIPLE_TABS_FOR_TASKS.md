# ✅ Каждая задача в своей вкладке браузера!

## 🎯 Проблема

Пользователь видел только одну вкладку браузера, хотя запускал несколько задач перераспределения одновременно.

### Причина:
Все задачи использовали одну и ту же страницу (`browser.page`) браузера, работая по очереди в одной вкладке.

## ✅ Решение

Теперь **каждая задача создает свою вкладку** в браузере пользователя и работает в ней независимо!

---

## 🔧 Технические изменения

### 1. Добавлен метод создания новых вкладок в BrowserManager

**Файл:** `wb_bot/app/services/browser_manager.py`

```python
async def create_new_tab(self, user_id: int):
    """Создает новую вкладку в браузере пользователя и возвращает Page."""
    browser = self._browsers.get(user_id)
    if not browser or not browser.context:
        return None
    
    # Создаем новую страницу (вкладку) в существующем контексте
    new_page = await browser.context.new_page()
    logger.info(f"📄 Создана новая вкладка для пользователя {user_id}")
    return new_page
```

### 2. RedistributionTask хранит ссылку на свою вкладку

**Файл:** `wb_bot/app/bot/handlers/redistribution.py`

```python
class RedistributionTask:
    def __init__(self, ...):
        # ... другие поля
        self.page = None  # ✅ Своя вкладка браузера для этой задачи
```

### 3. Каждая задача создает свою вкладку при запуске

```python
async def run_redistribution_task_in_background(user_id, task, bot):
    # Создаем новую вкладку для этой задачи
    task.page = await browser_manager.create_new_tab(user_id)
    logger.info(f"📄 Задача #{task.task_id} работает в своей вкладке")
    
    # Получаем браузер
    browser = await browser_manager.get_browser(user_id)
    
    # Сохраняем оригинальную страницу
    original_page = browser.page
    
    while attempts < max_attempts:
        try:
            # Временно подменяем страницу на страницу задачи
            browser.page = task.page
            
            try:
                # Работаем с redistribution_service
                await redistribution_service.close_and_reopen_redistribution(...)
                await redistribution_service.select_warehouse(...)
                # ... другие операции
            
            finally:
                # Всегда восстанавливаем оригинальную страницу
                browser.page = original_page
        
        except Exception as e:
            # обработка ошибок
```

### 4. Вкладка закрывается при завершении задачи

```python
# При успехе
await task.page.close()

# При достижении лимита
if task.page:
    await task.page.close()

# При отмене
if task.page:
    await task.page.close()

# При ошибке
if task.page:
    await task.page.close()
```

## 🎬 Как это работает

### Запуск первой задачи:

```
1. Пользователь создает задачу #1
2. Открывается браузер (если еще не открыт)
3. Создается вкладка #1 для задачи
4. Задача #1 работает во вкладке #1

Пользователь видит: 1 вкладку браузера
```

### Запуск второй задачи:

```
1. Пользователь создает задачу #2
2. Браузер уже открыт (переиспользуется)
3. Создается вкладка #2 для задачи
4. Задача #2 работает во вкладке #2
5. Задача #1 продолжает работать во вкладке #1

Пользователь видит: 2 вкладки браузера ✅
```

### Запуск третьей задачи:

```
1. Пользователь создает задачу #3
2. Браузер уже открыт
3. Создается вкладка #3
4. Все 3 задачи работают параллельно

Пользователь видит: 3 вкладки браузера ✅
```

## 🔄 Механизм подмены страницы

Чтобы `redistribution_service` работал с нужной вкладкой, используется временная подмена:

```python
# Сохраняем оригинальную страницу
original_page = browser.page

# Перед работой задачи
browser.page = task.page  # Подменяем на вкладку задачи

try:
    # redistribution_service использует browser.page
    # и работает с нужной вкладкой!
    await redistribution_service.select_warehouse(...)
finally:
    # Восстанавливаем
    browser.page = original_page
```

Это гарантирует что:
- ✅ Каждая задача работает в своей вкладке
- ✅ Задачи не мешают друг другу
- ✅ Не нужно менять redistribution_service

## ⚠️ Важно

### Браузер должен быть в НЕ headless режиме:
Чтобы видеть вкладки, браузер должен запускаться с `headless=False`.

### Одна основная страница:
Первая вкладка (`browser.page`) остается неизменной - это основная страница браузера.

### Автоматическое закрытие:
Вкладки задач автоматически закрываются при:
- Успешном выполнении
- Достижении лимита попыток
- Отмене задачи
- Ошибке
